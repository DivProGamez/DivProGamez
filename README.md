## Current Exploration

### GameSight AI — Proposed AI Game-Testing Agent

I'm exploring the idea of an **AI-powered quality-assurance agent for browser-based games**. The goal is to combine visual understanding, game interaction, and automated reporting to help developers discover and reproduce gameplay problems.

Potential capabilities include:

- Observing browser gameplay and identifying relevant screen elements.
- Sending keyboard and controller-style inputs through a test runner.
- Detecting problems such as stuck characters, input failures, and broken progression.
- Generating reproducible bug reports with screenshots and clear steps.

**Status:** Concept / proposed hackathon project — not presented as an already completed product. Model integrations depend on supported Meta APIs and event access.
